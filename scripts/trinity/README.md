# FRAME.9 Trinity semantic prototype

This module is a deterministic, local prototype. It provides:

- sourced genealogy assertions with cycle and reference validation;
- evidence-matched interpretive candidates that preserve alternatives;
- deny-by-default command-block validation.

It does **not** import a canonical biblical corpus, establish historical truth, infer genetic relationships, diagnose or recommend treatment, process real neural signals, or control physical devices. Interpretations always require human review. Biomedical and textual-semantic data remain separate domains.

Run tests with:

```sh
node --test scripts/trinity/semantic-engine.test.mjs
```
